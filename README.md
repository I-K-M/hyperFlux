# HyperFlux

HyperFlux is a personal sandbox for learning full-stack development. This project helped me understand how authentication works and allows me to build features that I find useful.

## What I'm Doing Here

- Building both frontend and backend components from scratch.
- Implementing authentication flows to grasp their inner workings.
- Using Docker Compose to manage services and streamline development.

## Stack

- Frontend: react
- Backend: node, express
- Containerization: docker

Work in progress.
